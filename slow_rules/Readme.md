The rules were extracted using the ULM programme and are derived from cracked hashes from the potfile. They have been sorted and split using splitlen.bin into smaller files. They were compiled into several files of five lengths each for the append and prepend charsets.

They have not yet been debugged for relevance, but maybe someone will find it useful. As a point of interest, I will say that I was able to clean up a ~800k hash file very quickly using these rules.
The main use of these rules is with basewords or a splitlen wordlist file.

Good base wordlist can be download [here](https://mega.nz/file/wT010BTL#N5ZuQsgM7rdvUMKHeFy_AuVKKrN94sBKihoxn0XMFGE).
